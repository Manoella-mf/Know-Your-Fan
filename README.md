# Know-Your-Fan
Challenge #2

Este projeto tem como objetivo desenvolver uma plataforma para coleta e validação de dados essenciais dos usuários, como nome, endereço, CPF, além de informações sobre interesses, atividades, eventos e compras realizadas no último ano. A plataforma também permite o upload de documentos e valida a identidade do usuário e autenticação segura.

## Principais tecnologias
Firebase (plataforma principal do projeto):

Firebase Database: Armazenamento de dados estruturados e não estruturados.

Firebase Authentication: Gerenciamento seguro de autenticação de usuários.

Firebase Storage: Armazenamento e gerenciamento de documentos e arquivos.

Firebase Functions: Execução de lógica de backend acionada por eventos.

## Tecnologias utilizadas
Frontend: JavaScript + HTML/CSS

Backend: Java

Plataforma Cloud: Firebase (Database, Authentication, Storage, Functions)
